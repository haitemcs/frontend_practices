# Frontend Practices

A collection of small HTML and CSS exercises.

## Projects

| Folder | Exercise |
| --- | --- |
| `01-profile-card` | Profile card with avatar and skill labels |
| `02-signup-button` | Centered register button with a hover state |
| `03-product-card` | E-commerce product card |

## Run a project

Open the project's `index.html` file in your browser.

## Images

Add the following image files to their matching folders:

- `01-profile-card/avatar.jpg`
- `03-product-card/shirt.jpg`
